slide
-----

The classic slide puzzle

Written in C with ncurses to provide a TUI

# Usage
Usage: `slide [OPTIONS]`

```
Options
  -h, --help
          Show this help message
      --no-colour
          Disable colours
      --seed <seed> 
          Set the seed for generating the puzzle
      --size <size>
          Set the size of the grid for this puzzle
```

# Controls

Use `WASD`, `HJKL`, or the Arrow Keys to change the highlighted tile 

`SPACE` to move highlighted tile into the empty square
